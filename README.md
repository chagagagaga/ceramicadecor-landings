и раздельная аналитика по каждому направлению.

## Почему один репозиторий, а не восемь

Восемь направлений продают один бренд. В отдельных репозиториях дизайн
разъезжается на второй же итерации: правку кнопки внесли в камины, забыли
в барбекю. Здесь `assets/css/system.css` один на всех — меняется в одном месте.

Раздельные адреса при этом сохраняются: каждое направление живёт в своей папке,
получает свою кампанию в Директе, свои цели в Метрике и свою отчётность.
Позже каждую папку можно увести на отдельный поддомен без переписывания кода.

## Согласованные решения (07.08.2026)

| Вопрос | Решение |
|---|---|
| Эталонное направление | **Барбекю-комплексы** — по его дизайну собираются остальные шесть |
| Цены на странице | Обе колонки: «от X за облицовку» крупно, «под ключ от Y» рядом |
| Приём заявок | Существующий `api/lead` на ceramic-decor.ru — лиды в один контур с ЛСО-CRM |
| География | Москва и МО с монтажом, отдельным блоком — отгрузка облицовки по России |
| Дизайн | Один проход Claude Design по эталону, остальные клонируются вручную |


## Стандарт лендинга (25.08.2026)

Все семь посадочных приведены к единому своду правил — он лежит в
`docs/LANDING_STANDARD.md` и собран на проекте «Первый Луч» по итогам аудита
подрядчика по Директу. Что применено здесь:

| Правило | Как реализовано |
|---|---|
| Доказательство до аргументов | Портфолио поднято на второе место, до каталога |
| Цена не кричит при загрузке | В конфигураторе кнопка «Показать стоимость»; первое же действие раскрывает цену само |
| В окне заявки только форма | Блок «Ваш расчёт» убран — человек его уже видел |
| FAQ не простыня | Шесть вопросов видно сразу, остальные по кнопке; в микроразметке все |
| Цифры доверия в два столбца | На телефоне столбиком они съедали пол-экрана |
| Зона нажатия от 32 px | Ссылки навигации, подвала, политики и чипы фильтров |
| Кнопки заметнее | Крупнее и с тенью у главной |
| Без висячих предлогов | Проход по DOM после отрисовки приклеивает короткие слова |
| Скорость | `content-visibility` на нижних секциях, размеры и `decoding=async` у всех картинок |

## Проверка перед деплоем

```bash
npm test              # структура, битые ссылки и картинки, интерактив всех семи
python3 -m http.server 8099 &
npm run visual        # настоящий Chrome на 360/390/768/1280/1440
```

`docs/audit.mjs` гоняет все семь направлений в jsdom и проверяет порядок
секций, скрытую цену, отсутствие блока расчёта в модалке, битые якоря и
картинки без размеров. `docs/visual.mjs` открывает их в Chrome и ищет
горизонтальный скролл, выход за край, обрезанный текст и мелкие цели.

## Дизайн-система

`assets/css/system.css` — токены сняты с боевого сайта:

| Роль | Значение |
|---|---|
| Фон | `#101010` |
| Акцент действия | `#cb3b25` терракота |
| Акцент цены | `#ffa15e` янтарь |
| Статус «готово» | `#93d200` |
| Заголовки | TT Ramillas |
| Текст | TT Commons Pro |

Шрифты лицензионные и в репозиторий не положены — раздавать их с публичного
хостинга нельзя. Перед боевым запуском файлы кладутся в `assets/fonts/`,
до тех пор работает подобранный по метрикам системный стек.

## Структура посадочной

Каждое направление повторяет схему, обкатанную на «Первом Луче»:

```
<направление>/
  index.html              страница целиком
  assets/js/pricing.js    все цены и тексты направления
  assets/js/quiz.js       конфигуратор первого экрана
  assets/js/main.js       рендер секций, фильтры, галерея
  assets/js/lead.js       отправка заявок
  assets/img/             фотографии направления
```

Общее: `assets/css/system.css` в корне репозитория.
