# Приёмник заявок — общий на восемь посадочных

Заявка с любой посадочной уходит одним запросом сюда, а приёмник рассылает её
**одновременно** в четыре места:

| Куда | Зачем |
|---|---|
| **ЛСО** | основной приёмник. Из него потом идёт выгрузка офлайн-конверсий в Метрику |
| **Telegram** | менеджеру, мгновенно. Ботов два: у «Первого Луча» свой, у Керамики свой |
| **Google-таблица** | страховка. Если ЛСО не ответила, заявка всё равно записана и видна глазами |
| **Почта** | необязательный дубль, если задан ключ Resend |

Ответ отдаётся `200`, если сработал хотя бы один канал: заявка, дошедшая
в Telegram, но не дошедшая в ЛСО, не считается потерянной.

---

## Зачем вообще нужен сервер

Посадочные лежат на статическом хостинге — своего бэкенда у них нет.
А токены ботов и ключ Google в браузер класть нельзя: любой человек откроет
исходник страницы и заберёт их. Значит нужен хоть какой-то серверный кусок,
который держит секреты у себя.

Cloudflare Workers выбран потому, что он бесплатный на наших объёмах,
разворачивается за пять минут и **позволяет нам самим настроить разрешение
приёма по `Origin`** — иначе пришлось бы ждать, пока это сделают на стороне ЛСО.

Работает и без Cloudflare — той же цели служит любой серверный обработчик.
Если ЛСО согласится принимать заявки напрямую и сама раскидывать дубли,
приёмник можно выключить, поменяв один адрес в конфиге посадочных.

## Что куда попадает

Площадка определяется полем `site_key`, оно приходит с посадочной:

| `site_key` | Бот | Вкладка в таблице |
|---|---|---|
| `luch-banya` | Первый Луч | Первый Луч |
| `cd-barbekyu-kompleksy` | Керамика | Барбекю комплексы |
| `cd-kaminy` | Керамика | Камины |
| `cd-izraztsy` | Керамика | Изразцы |
| `cd-pechi-kaminy` | Керамика | Печи-камины |
| `cd-bannye-portaly` | Керамика | Банные порталы |
| `cd-russkie-pechi` | Керамика | Русские печи |
| `cd-otopitelnye-pechi` | Керамика | Отопительные печи |

Незнакомый ключ не роняется: заявка уходит боту по префиксу и пишется
на вкладку своего бренда.

## Развёртывание

### 1. Боты и группы

Боты уже созданы: `luch_ya_leads_bot` и `cd_new_pages_bot`. Для каждого
нужна группа, куда он добавлен **администратором** — без прав администратора
бот не увидит сообщения и не сможет писать.

`chat_id` группы: напишите в неё любое сообщение и откройте
`https://api.telegram.org/bot<ТОКЕН>/getUpdates`. Найдите `"chat":{"id":-100…}`.
У групп id отрицательный — записывать вместе с минусом.

### 2. Доступ к Google-таблице

Сервисному аккаунту нужно выдать право **редактора** на таблицу с дублями.
Почта аккаунта — та же, что используется в остальных проектах.

Вкладки и шапки уже созданы, руками ничего заводить не нужно.

### 3. Секреты

```bash
npm install -g wrangler
wrangler login

cd api
wrangler secret put TG_TOKEN_LUCH
wrangler secret put TG_CHAT_LUCH
wrangler secret put TG_TOKEN_CD
wrangler secret put TG_CHAT_CD
wrangler secret put LSO_ENDPOINT
wrangler secret put SHEET_ID
wrangler secret put GOOGLE_SA_EMAIL
wrangler secret put GOOGLE_SA_KEY     # PEM целиком, вместе со строками BEGIN/END
```

Значения вводятся в ответ на запрос и **никуда не записываются** — ни в этот
репозиторий, ни в историю команд. Посмотреть их потом нельзя, только заменить.

### 4. Раскатка

```bash
wrangler deploy
```

Адрес получится вида `https://cd-lead.<аккаунт>.workers.dev`. Его нужно
прописать в конфиг посадочных — в `build.py` (поле `endpoint`) и в
`assets/js/lead.js` «Первого Луча».

### 5. Проверка

```bash
curl https://cd-lead.<аккаунт>.workers.dev/health
```

Затем отправить тестовую заявку с посадочной и убедиться, что она пришла
в нужную группу, легла на нужную вкладку таблицы и завелась в ЛСО.

## Безопасность

- Секреты живут только в Cloudflare. В репозитории, в коде страниц и в браузере
  их нет — открыв исходник посадочной, токен забрать нельзя.
- `Origin` проверяется по белому списку. Звёздочка не ставится: иначе приёмник
  можно было бы дёргать с любой страницы в интернете.
- Заявки с ссылкой в имени или комментарии отбрасываются как спам, но в ответ
  всё равно уходит `200` — иначе бот поймёт, что фильтр сработал, и начнёт
  подбирать обход.
- Если токен бота где-то засветился (переписка, скриншот, чужой компьютер),
  его нужно отозвать: @BotFather → `/revoke`. Старый перестанет работать сразу,
  новый прописывается одной командой `wrangler secret put`.
